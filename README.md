💧 Own Solana Faucet

A simple Solana Faucet built using React + Web3 that allows users to request SOL tokens easily.
Currently runs in a local development environment.

🚀 Features

Send SOL tokens from a local wallet
User-friendly React interface
Web3 wallet integration
Built with Vite for fast development

⚙️ Installation & Setup
# Clone the repository
git clone https://github.com/mansiverma897993/React-web3-wallet.git

# Navigate to the project folder
cd React-web3-wallet

# Install dependencies
npm install

# Run the development server
npm run dev

Then open the local URL shown in your terminal (usually http://localhost:5173/).

🧠 Tech Stack

React.js
Vite
Solana Web3.js
